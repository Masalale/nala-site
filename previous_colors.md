# Previous Color Palette

Reference for the original color scheme before the "Peach & Deep Green" update (Feb 6, 2026).

## CSS Variables

```css
@theme {
  --color-primary: #facf80;    /* Light Gold */
  --color-secondary: #727b68;  /* Sage Green */
  --color-accent: #d4a574;     /* Muted Orange/Terra Cotta */
  --color-background: #faf8f3; /* Off-White/Cream */
  --color-surface: #ffffff;    /* Pure White */
  --color-text: #3d3d3d;       /* Dark Gray */
  --color-text-muted: #6b6b6b; /* Medium Gray */
}
```

## Description
- **Primary**: Soft, pale gold.
- **Secondary**: Muted sage green.
- **Background**: Very light cream/off-white.
- **Text**: Dark gray, not black.
